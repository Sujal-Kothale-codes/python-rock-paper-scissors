# Rock, Paper, Scissors Game

A simple command-line Rock, Paper, Scissors game built using Python. Play against the computer and see who wins!

## Features

- Play against the computer.
- Computer generates a random choice.
- Displays both the player's and computer's choices.
- Determines the winner using conditional statements.
- Beginner-friendly Python implementation.

## Technologies Used

- Python 3
- Random module
- Conditional statements
- Lists and user input

## How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/python-rock-paper-scissors.git
   ```

3. Open the project folder.
4. Run the Python file:

   ```bash
   python main.py
   ```

## How to Play

1. Run the program.
2. Enter `rock`, `paper`, or `scissors`.
3. The computer randomly selects its move.
4. The program displays both choices and determines the result.
